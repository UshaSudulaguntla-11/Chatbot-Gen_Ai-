# ⚛️ Physics & Chemistry Chatbot

A **web-based AI chatbot** that answers **Physics and Chemistry questions only**.  
Built with **HTML, CSS, JavaScript** for the frontend and **Flask** for the backend, using **Gemini AI** for intelligent answers.

---

## 🌟 Features

- Answers **Physics & Chemistry questions** only.  
- Simple, **interactive web interface**.  
- Fast and lightweight.  
- Powered by **Gemini AI API**.  

---

## 🖥 Tech Stack

| Frontend       | Backend | AI        |
|----------------|---------|-----------|
| HTML, CSS, JS  | Flask   | Gemini AI |

---

## 🚀 How It Works

1. User types a question in the **chatbox**.  
2. **Frontend JavaScript** sends the question to the **Flask backend**.  
3. Flask forwards the question to the **Gemini AI API**.  
4. AI responds **with answers limited to Physics & Chemistry**.  
5. Frontend displays the **response in the chat window**.  

**Flow Diagram:**  
User → Frontend JS → Flask Backend → Gemini AI API → Backend → Frontend → User

Install dependencies:
pip install -r requirements.txt

Run the app:
python main.py

Open your browser: http://127.0.0.1:8013
